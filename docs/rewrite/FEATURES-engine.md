# Engine feature inventory

This inventory records the complete Python engine, command-line interface and HTTP surface at the Phase 1 baseline. Each item is independently testable. A related legacy test is orientation evidence, not proof that the rewrite passes. Rewrite-proof links mirror the canonical report and its actual passing tests; Pending rows retain their missing acceptance.

The rewrite must preserve compatible behavior and data while fixing the bugs in [known-bugs.md](known-bugs.md). Rows explicitly marked as rewrite corrections describe those required fixes; they must not be replaced by tests that merely reproduce the defect. A route's positive fixture, negative fixtures and SSE samples are captured separately under [tests/fixtures/api](../../tests/fixtures/api/).

The HTTP routes share the safety/error contract below. Route records name request fields, defaults and response shapes; the fixture manifest supplies real bodies, headers and status codes. All API routes require the header token except health and the explicitly named query-token streams/downloads.
