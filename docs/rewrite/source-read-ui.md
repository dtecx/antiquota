## Observed dependency boundaries

- The legacy UI is vanilla JavaScript and DOM/CSS, with no component framework. The new Svelte and TypeScript implementation is an explicit replacement requirement.
- The legacy usage chart is hand-built SVG, not a chart library. The rewrite chart library must retain its observable statistics, daily hover breakdown and edge-aware tooltip placement.
- Legacy recording uses an AudioContext ScriptProcessor to produce PCM WAV; the requested rewrite uses MediaRecorder directly while retaining transcription and the silence guard.
- The shell uses native plugins for window state, tray, notifications, clipboard, opener, save dialogs and autostart. Its engine adapter reads engine.json and shares the existing daemon rather than owning session behavior.
- Legacy release builds package Python with PyInstaller. The requested Rust binary replaces that bundling path; no deletion or cutover happened during inventory.
