# ADR 0015: Dictation and attachments

Status: Accepted for Slice 8.

Attachments upload as raw request bodies, up to 25 MB, with the URL-encoded name in `X-Filename`. The store sanitizes the base name, adds `-2`, `-3` suffixes on collisions and keeps files in the session's `attachments` folder. A turn passes only files whose canonical paths stay inside that folder: outside paths, folders and escaping symlinks are dropped. The prompt lists the files after the message, and agy receives the folder through `--add-dir`. Attachment-only messages are allowed, and queued messages keep their attachment paths until their turn. Downloads take the token from the query, because images and links cannot send headers. The rewrite decodes the file name once before the containment check, so names with spaces download (B-021).

Dictation saves the recording under `state/dictation`, leases a Gemini account (waiting up to two minutes when every account is busy, instead of the legacy unbounded wait) and asks agy in a fresh JSON conversation with Gemini 3.8 Flash High, folder access and a 180 second limit. Unlike the legacy call it does not skip permissions, and the prompt asks agy to use its file viewer only. With tools allowed, a live run converted the audio with ffmpeg, deleted files and read other conversations, taking 220–400 seconds and up to 540k tokens; view-only, the same recording took 51 seconds and 45k tokens (W-010). An empty or `NO_SPEECH` answer becomes empty text, and a failed or malformed answer is an error. The recording is deleted and the lease released after every outcome; no session or conversation is involved.

The UI uses browser speech recognition where it exists (not in the desktop web view), and otherwise records with MediaRecorder directly (F-664, F-1055). An analyser node measures the input level only for the silence guard: recordings shorter than half a second or with a peak below 0.01 are refused before upload. The recorder prefers WebM Opus, then MP4, which is the only container WebKit records. Live agy checks on 2026-10-08 transcribed Chromium's WebM Opus, Chromium's Opus-in-MP4 and an AAC M4A file of the same sentence correctly. AAC MP4 from the desktop web view is checked again with the native shell in Slice 10.

Playwright replaces the microphone with recorded WAV files (`ui/e2e/audio/speech.wav`, made with the macOS `say` command, and a silent file), so the recording path, the silence guard and the inserted transcription are proven in a real browser against the fake agent. File drops are handled window-wide, so a drop without a session asks for one instead of opening the file in the browser. Opening another session clears unsent attachments, as before.
